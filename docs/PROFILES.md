# Dotfield Profile Specification

Profiles in **Dotfield** are defined in TOML and serve as the single source of truth for your desktop environment.

## 1. Schema Overview

A Dotfield profile specifies:
1. `[meta]`: Profile metadata (name, description, author, version).
2. `[compositor]`: Active compositor selection and window management options.
3. `[apps]`: Semantic default applications.
4. `[bindings]`: High-level keybindings mapped to semantic actions.
5. `[theme]`: Color palette tokens, typography, and styling.
6. `[security]`: Sandboxing policies and network isolation toggles.

---

## 2. Profile Structure Example

```toml
[meta]
name = "minimal"
description = "Ultra-lightweight Wayland rice with zero overhead"
version = "0.1.0"

[compositor]
target = "sway" # Options: "sway", "niri"
gaps_inner = 6
gaps_outer = 4
border_width = 2

[apps]
terminal = "foot"
launcher = "fuzzel"
editor = "nvim"
multiplexer = "zellij"
file_manager = "foot -e yazi"
browser = "firefox"
bar = "i3status-rust"
notifications = "mako"

[bindings]
# Modifiers: "Super", "Alt", "Ctrl", "Shift"
terminal = "Super+Return"
launcher = "Super+space"
editor = "Super+e"
file_manager = "Super+Shift+Return"
close_window = "Super+q"
toggle_floating = "Super+Shift+space"
fullscreen = "Super+f"
reload_config = "Super+Shift+r"

[theme]
palette = "catppuccin-mocha"
font_sans = "Inter 10"
font_mono = "JetBrainsMono Nerd Font 10"
accent_color = "#89b4fa"
background = "#1e1e2e"
foreground = "#cdd6f4"

[security]
isolate_browser = true
enforce_firejail = false
enforce_nftables = false
```

---

## 3. How Keybindings Compile

When `dotfield apply` runs, the `[bindings]` table is compiled into the target compositor's native syntax:

### For Sway (`target = "sway"`):
```sway
# Generated by dotfield. Do not edit manually.
bindsym Mod4+Return exec foot
bindsym Mod4+space exec fuzzel
bindsym Mod4+e exec nvim
bindsym Mod4+Shift+Return exec foot -e yazi
bindsym Mod4+q kill
bindsym Mod4+Shift+space floating toggle
bindsym Mod4+f fullscreen toggle
bindsym Mod4+Shift+r reload
```

### For Niri (`target = "niri"`):
```kdl
// Generated by dotfield. Do not edit manually.
binds {
    Mod+Return { spawn "foot"; }
    Mod+Space { spawn "fuzzel"; }
    Mod+E { spawn "nvim"; }
    Mod+Shift+Return { spawn "foot" "-e" "yazi"; }
    Mod+Q { close-window; }
    Mod+Shift+Space { toggle-window-floating; }
    Mod+F { maximize-column; }
}
```
